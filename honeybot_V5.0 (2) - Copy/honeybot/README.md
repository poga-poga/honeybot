# FactoryShield: Multi-Layer Industrial Enterprise Honeypot

> **العنوان الأكاديمي:**
> **FactoryShield: A Multi-Layer Industrial Enterprise Honeypot for Detecting Sensitive Data Exfiltration, Privilege Abuse, and Lateral Movement**
> *(بيئة خداع سيبراني متعددة الطبقات لشركة تصنيع صناعي، لاكتشاف تسريب البيانات الحساسة وإساءة استخدام الصلاحيات والانتقال بين الأجهزة)*

---

## 1. ملخص المشروع (Executive Summary)

يمثل **FactoryShield** نظام خداع سيبراني دفاعي (Cyber Deception Platform) مبنياً على محاكاة واقعية لشركة تصنيع صناعي افتراضية باسم **Jordan Industrial Manufacturing (JIM)**.

يحتوي النظام على موارد خادعة (Decoys) وبيانات اصطناعية (Synthetic Data) موزعة عبر أقسام الشركة، ويعتمد على **محرك كشف حتمي مفسّر (Explainable Deterministic Detection Engine)** يربط بين:
1. **مؤشرات الفخاخ (Honeytokens):** ملفات CAD، سجلات قواعد بيانات، حسابات وهمية، ومفاتيح API.
2. **سياق الصلاحيات (RBAC Context):** مصفوفة صلاحيات الموظفين وأقسامهم.
3. **التسلسل الزمني والمكاني (Temporal & Lateral Movement Correlation):** تتبع مسارات القفزات بين الأجهزة عبر شبكات المصنع المختلفة.

## 2. معمارية شبكات الشركة الافتراضية (Purdue Model Architecture)

تتوزع بيئة العمل إلى 4 شبكات افتراضية معزولة:

| الشبكة | النطاق (Subnet) | الوظيفة والأجهزة |
|--------|----------------|------------------|
| **Office Network** | `192.168.10.0/24` | أجهزة الموظفين والإدارة (`WS-MGMT-01`, `WS-ENG-01`, `WS-PROD-01`, `WS-HR-01`, `WS-IT-01`) |
| **Engineering Network** | `192.168.20.0/24` | خادم التصاميم الهندسية ومستودع مخططات CAD (`cad-srv01`, `cad-repo01`) |
| **Production Simulation Network** | `192.168.30.0/24` | خادم قاعدة بيانات الإنتاج ومحاكي PLC الصناعي وواجهة HMI (`db-prod01`, `plc-sim01`, `hmi-prod01`) |
| **Isolated Security Monitoring Network** | `192.168.99.0/24` | خادم محرك الكشف ولوحة المراقبة والتحليل الجنائي (`sec-mon01`) |

## 5. محرك الكشف الحتمي ونظام تقييم الخطورة (Scoring Engine)

يعتمد المحرك على **5 قواعد حتمية (R1 إلى R5)** مع نظام نقاط تراكمي (0 إلى 100):

| القاعدة | الشرط والمعيار | النقاط | الوصف |
|---------|----------------|--------|-------|
| **R1** | لمس أي مورد خادع (Canary Trigger) | +40 نقطة | الوصول إلى File, DB, Account, أو API Canary |
| **R2** | مخالفة سياسة الوصول (Privilege Violation) | +20 نقطة | محاولة موظف الوصول لمورد خارج صلاحيات قسمه |
| **R3** | تسلسل نشاط عبر أقسام متعددة | +15 نقطة | وصول متتابع لموارد تتبع أقساماً مختلفة |
| **R4** | مؤشر تسريب بيانات (Data Exfiltration) | +20 نقطة | وصول لملفات حساسة يتبعه تصدير بيانات اصطناعية |
| **R5** | انتقال متسلسل بين الأجهزة (Lateral Pivot) | +20 نقطة | مسار انتقال عبر جهاز وسيط (Workstation -> Intermediate -> Target) |

### تصنيف مستويات الخطورة:
- **0 – 29:** منخفض (Low)
- **30 – 59:** متوسط (Medium)
- **60 – 79:** مرتفع (High)
- **80 – 100:** حرج (Critical)

## 7. التشغيل السريع (Quickstart)

### تشغيل لوحة المراقبة ومحرك الكشف:
```bash
python run.py
```
ثم افتح المتصفح على الرابط:
👉 **`http://localhost:5000`**

### تشغيل محاكي السيناريوهات الفردية عبر الـ Terminal:
```bash
# محاكاة تسريب بيانات هندسية
python simulate_scenarios.py exfiltration

# محاكاة إساءة صلاحيات (موظف HR يحاول الوصول لخادم التصاميم)
python simulate_scenarios.py privilege

# محاكاة انتقال متسلسل بين الأجهزة (Lateral Movement Pivot)
python simulate_scenarios.py lateral

# محاكاة نشاط مصرح وطبيعي
python simulate_scenarios.py normal
```

### توليد تقرير التقييم الأكاديمي الشامل (100 سيناريو):
```bash
python benchmark_report.py
```
يقوم هذا الأمر بإجراء المقارنة الإحصائية وحفظ التقرير بصيغة JSON داخل:
`benchmark_evaluation_results.json`
